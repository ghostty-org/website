---
title: Cursor Backward Tabulation (CBT)
description: Move the cursor `n` tabs left.
---

<VTSequence sequence={["CSI", "Pn", "Z"]} />

If `n` is omitted, `n` defaults to 1. Ghostty treats a value of 0 as a
request to move zero tabs, so the cursor does not move. Xterm treats a
value of 0 the same as 1.

The leftmost valid column for this operation is the first column. If
[origin mode](#TODO) is enabled, then the leftmost valid column for this
operation is the [left margin](#TODO). Without origin mode, the left
margin has no effect and the cursor can tab backward past it.

Move the cursor left until the cursor position is on a tabstop. If the
cursor would move past the leftmost valid column, the cursor remains at
the leftmost valid column and the operation completes. Repeat this process
`n` times.

Tabstops are dynamic and can be set with escape sequences such as
[horizontal tab set (HTS)](#TODO), [tab clear (TBC)](/docs/vt/csi/tbc), etc.
A terminal emulator may default tabstops at any interval, though an interval
of 8 spaces is most common.

## Standards

CBT is defined by [ECMA-48][ecma48-cbt], which moves the cursor to the `n`th
preceding tabstop and gives `n` a default of 1. ECMA-48 does not say what
happens when there are fewer than `n` tabstops to the left of the cursor.
The [VT510 manual][vt510-cbt] fills that gap: the cursor stops at the
first column.

[DEC STD 070][std070], DEC's specification for the VT100 through VT400
terminals, does not include CBT. It does define the tabstop model CBT
moves through: [a tabstop can be set at every column][std070-tabs], and the
default tabstops are at every eighth column starting with column 9. It
also defines the other tab controls: [TBC][std070-tbc],
[HT][std070-ht], and [HTS][std070-hts].

Neither standard describes how CBT interacts with margins. Ghostty follows
xterm, which limits CBT to the left margin only when origin mode is
enabled.

## Validation

### CBT V-1: Left Beyond First Column

```bash
printf "\033[?5W" # reset tab stops
printf "\033[10Z"
printf "A"
```

```
|Ac________|
```

### CBT V-2: Left Starting After Tab Stop

```bash
printf "\033[?5W" # reset tab stops
printf "\033[1;10H"
printf "X"
printf "\033[Z"
printf "A"
```

```
|________AX|
```

### CBT V-3: Left Starting on Tabstop

```bash
printf "\033[?5W" # reset tab stops
printf "\033[1;9H"
printf "X"
printf "\033[1;9H"
printf "\033[Z"
printf "A"
```

```
|A_______X_|
```

### CBT V-4: Left Margin with Origin Mode

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[?5W" # reset tab stops
printf "\033[?6h" # enable origin mode
printf "\033[?69h" # enable left/right margins
printf "\033[3;6s" # scroll region left/right
printf "\033[1;2H" # move cursor in region
printf "X"
printf "\033[Z"
printf "A"
```

```
|__AX______|
```

### CBT V-5: Left Margin without Origin Mode

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[?5W" # reset tab stops
printf "\033[?69h" # enable left/right margins
printf "\033[3;10s" # scroll region left/right
printf "\033[1;6H" # move cursor in region
printf "\033[Z"
printf "A"
```

```
|Ac________|
```
