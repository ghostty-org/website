---
title: Cursor Horizontal Tabulation (CHT)
description: Move the cursor right `n` tabs.
---

<VTSequence sequence={["CSI", "Pn", "I"]} />

If `n` is omitted, `n` defaults to 1. Ghostty treats a value of 0 as a
request to move zero tabs, so the cursor does not move. Xterm treats a
value of 0 the same as 1.

The rightmost valid column for this operation is the rightmost column in
the terminal screen or the [right margin](#TODO), whichever is smaller.
This sequence does not change behavior with [origin mode](#TODO) set.

If the cursor is already to the right of the right margin, Ghostty does
not move it. Other terminals differ here; see [Standards](#standards).

Move the cursor right until the cursor position is on a tabstop. If the
cursor would move past the rightmost valid column, the cursor remains at
the rightmost valid column and the operation completes. Repeat this process
`n` times.

Tabstops are dynamic and can be set with escape sequences such as
[horizontal tab set (HTS)](#TODO), [tab clear (TBC)](/docs/vt/csi/tbc), etc.
A terminal emulator may default tabstops at any interval, though an interval
of 8 spaces is most common.

## Standards

CHT is defined by [ECMA-48][ecma48-cht], which moves the cursor to the `n`th
following tabstop and gives `n` a default of 1. The
[VT510 manual][vt510-cht] describes it the same way. Neither says what
happens when there are fewer than `n` tabstops to the right of the cursor,
or how CHT interacts with margins.

[DEC STD 070][std070], DEC's specification for the VT100 through VT400
terminals, does not include CHT. It does define the tabstop model CHT
moves through: [a tabstop can be set at every column][std070-tabs], and the
default tabstops are at every eighth column starting with column 9. Its
definition of [HT][std070-ht], which is a single forward tab, stops at the
right margin when no tabstop is reached before it. It also defines the
other tab controls: [TBC][std070-tbc] and [HTS][std070-hts].

Ghostty follows xterm and DEC STD 070's HT in stopping at the right
margin. The terminals disagree when the cursor starts to the right of the
right margin:

- [DEC STD 070's HT algorithm][std070-ht-algorithm] moves the cursor to
  the next tabstop, or to the last column of the line if there is none.
- Xterm moves the cursor left, to the right margin.
- Ghostty does not move the cursor.

## Validation

### CHT V-1: Right Beyond Last Column

```bash
printf "\033[?5W" # reset tab stops
printf "\033[100I" # assuming the test terminal has less than 800 columns
printf "A"
```

```
|_________A|
```

### CHT V-2: Right From Before a Tabstop

```bash
printf "\033[?5W" # reset tab stops
printf "\033[1;2H"
printf "A"
printf "\033[I"
printf "X"
```

```
|_A______X_|
```

### CHT V-3: Right Margin

```bash
printf "\033[1;1H" # move to top-left
printf "\033[0J" # clear screen
printf "\033[?5W" # reset tab stops
printf "\033[?69h" # enable left/right margins
printf "\033[3;6s" # scroll region left/right
printf "\033[1;1H" # move cursor in region
printf "X"
printf "\033[I"
printf "A"
```

```
|__AX______|
```
